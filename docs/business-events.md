# 来源变化

首次成交更正数量后，转售批次的存栏变化要核对可追踪的头数。

event-pending.json 表示来源目录已发现资料但正文尚未取得，event-complete.json 表示补取的原文字节已进入接收链。来源字段与既有资料的关系需根据业务事实核对。

# 成交更正与撤回

同一交易身份的新版次（如竞价公告 v2）替换当前数量，旧版原文仍留在账本供历史视图复现。transaction_retraction 通过 transaction_id 指向原成交，只扣减该笔交易的有效头数，不作为新交易，也不影响同批次其他成交。目录要求的来源尚未接收、版次尚未核对，或撤回指向的交易尚未取得时，相关批次存栏标记为待核并保留已有证据，不把缺少的交易按零头数处理。
